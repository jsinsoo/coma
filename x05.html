12정05-01 디지털 기술과 진로 설계

성취기준
디지털 기술이 사회에 미치는 영향력을 분석하고 발전 방향을 예측하여 진로를 설계한다.

디지털 사회가 진로에 미치는 다양한 영향력을 설명하고, 디지털 기술의 발전에 따른 사회 변화와 연계한 진로를 구체적으로 설계하여 미래 사회의 발전 방향에 대해 예측하고 통찰하려는 자세를 내면화할 수 있다.

핵심 개념

  • 디지털 기술은 직업의 형태, 업무 방식, 필요한 역량을 변화시킨다.
  • 인공지능, 빅데이터, 클라우드, 사물인터넷 등은 미래 진로 설계와 밀접하게 연결된다.
  • 진로 설계에서는 관심 분야, 필요한 디지털 역량, 사회 변화 전망을 함께 고려해야 한다.
  • 디지털 기술 발전은 기존 직업을 변화시키고 새로운 직업을 만들어낸다.

예제 파이썬 코드

# 디지털 기술과 관련된 진로 추천 예제
career_data = {
    "AI": "인공지능 개발자",
    "DATA": "데이터 분석가",
    "SECURITY": "정보보안 전문가",
    "DESIGN": "UX/UI 디자이너"
}

interest = "DATA"

if interest in career_data:
    career = career_data[interest]
else:
    career = "추가 탐색 필요"

print("관심 분야:", interest)
print("추천 진로:", career)

예상 출력

추천 진로: 데이터 분석가

OX 2. 디지털 사회에서는 새로운 직업이 생기고 기존 직업도 변화할 수 있다.
OX 3. 진로 설계에서는 사회 변화와 디지털 역량을 고려할 필요가 없다.

12정05-02 정보 보호와 정보 공유

성취기준
보호해야 할 정보와 공유해야 할 정보를 구분하고, 올바른 정보 보호 방법을 실천한다.

정보 보호와 정보 공유에 대해 명확히 설명하고, 개인정보 보호, 오ㆍ남용 방지 대책 등 다양한 실사례 탐색을 통한 정보 보호 방법을 실천하여 올바른 정보 보호 의식을 내면화할 수 있다.

핵심 개념

  • 개인정보, 비밀번호, 주민등록번호, 위치 정보 등은 보호해야 할 정보이다.
  • 공익적 자료, 출처가 명확한 공개 자료, 저작권을 지킨 자료는 조건에 맞게 공유할 수 있다.
  • 정보 공유 시에는 개인정보 노출, 저작권 침해, 허위 정보 확산을 주의해야 한다.
  • 정보 보호 실천에는 비밀번호 관리, 접근 권한 설정, 익명화, 출처 표시가 포함된다.

예제 파이썬 코드

# 공유 가능한 정보와 보호해야 할 정보 구분 예제
info_list = [
    {"name": "학교 급식 메뉴", "type": "공유 가능"},
    {"name": "학생 전화번호", "type": "보호 필요"},
    {"name": "공개 기상 데이터", "type": "공유 가능"},
    {"name": "계정 비밀번호", "type": "보호 필요"}
]

protected = []
shared = []

for info in info_list:
    if info["type"] == "보호 필요":
        protected.append(info["name"])
    else:
        shared.append(info["name"])

print("보호해야 할 정보:", protected)
print("공유 가능한 정보:", shared)

12정05-03 정보보안과 디지털 윤리

성취기준
정보보안의 필요성을 이해하고, 보안 기술을 활용하여 디지털 윤리를 실천한다.

정보보안의 개념과 필요성을 명확하게 설명하고 개인 암호 설정 및 변경, 기기 및 클라우드 접근 제어, 바이러스 백신 설정 등 상황에 따른 보안 기술을 적절히 활용하여 디지털 윤리를 실천하며 올바른 보안 의식을 내면화할 수 있다.

핵심 개념

  • 정보보안은 정보의 기밀성, 무결성, 가용성을 지키는 활동이다.
  • 강한 비밀번호, 2단계 인증, 접근 권한 설정은 계정 보호에 도움이 된다.
  • 백신 설정, 업데이트, 의심스러운 링크 주의는 악성코드 피해를 줄이는 방법이다.
  • 디지털 윤리는 타인의 정보와 권리를 존중하고 책임 있게 디지털 기술을 사용하는 태도이다.

예제 파이썬 코드

# 비밀번호 강도 검사 예제
password = "Info2025!"

has_length = len(password) >= 8
has_digit = any(ch.isdigit() for ch in password)
has_symbol = any(not ch.isalnum() for ch in password)

if has_length and has_digit and has_symbol:
    result = "강한 비밀번호"
else:
    result = "개선 필요"

print("비밀번호 길이 조건:", has_length)
print("숫자 포함:", has_digit)
print("특수문자 포함:", has_symbol)
print("판정:", result)

숫자 포함: True
특수문자 포함: True
판정: 강한 비밀번호

OX 1. 정보보안은 개인정보와 중요한 데이터를 보호하는 데 필요하다.
OX 2. 비밀번호는 짧고 단순할수록 안전하다.
OX 3. 2단계 인증은 계정 보안을 강화하는 방법이 될 수 있다.
OX 4. 의심스러운 링크를 함부로 클릭하지 않는 것은 보안 실천이다.
OX 5. 디지털 윤리는 온라인에서 타인의 권리와 정보를 존중하는 태도와 관련이 없다.
