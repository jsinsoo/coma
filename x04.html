12정04-01 지능 에이전트와 인간-인공지능 관계

성취기준
지능 에이전트의 개념과 특성을 이해하고, 인간과 인공지능의 관계를 분석한다.

지능 에이전트의 개념과 특성을 명확하게 설명하고, 다양한 인공지능 제품이나 서비스에서 지능 에이전트의 역할을 탐색하여 인간과 인공지능의 관계에 대해 올바르게 인식할 수 있다.

핵심 개념

  • 지능 에이전트는 환경을 인식하고 판단하며 행동하는 시스템이다.
  • 센서는 환경 정보를 수집하고, 판단 과정은 상태에 따라 행동을 결정한다.
  • AI 비서, 스마트홈, 자율주행 자동차는 지능 에이전트의 예가 될 수 있다.
  • 인공지능은 인간을 무조건 대체하는 존재가 아니라 협력적 문제 해결 도구가 될 수 있다.

예제 파이썬 코드

class SmartAgent:
    def __init__(self, name):
        self.name = name

    def sense(self, temperature):
        if temperature > 28:
            return "덥다"
        else:
            return "쾌적하다"

    def act(self, state):
        if state == "덥다":
            return "에어컨 켜기"
        else:
            return "대기"

agent = SmartAgent("AI 비서")

state = agent.sense(30)
action = agent.act(state)

print("상태:", state)
print("행동:", action)

예상 출력

상태: 덥다
행동: 에어컨 켜기

OX 3. 센서는 환경 정보를 수집하는 역할을 한다.
OX 4. 인공지능은 인간과 협력할 수 없다.

12정04-02 기계학습 개념과 지도학습·비지도학습 비교

성취기준
기계학습의 개념을 이해하고, 지도학습과 비지도학습의 차이를 비교ㆍ분석한다.

기계학습의 개념과 유형을 명확하게 설명하고, 지도학습과 비지도학습의 차이를 정확하게 비교ㆍ분석할 수 있다.

핵심 개념

  • 기계학습은 데이터를 기반으로 규칙이나 패턴을 학습하는 인공지능 기술이다.
  • 지도학습은 입력 데이터와 정답(label)을 함께 사용한다.
  • 비지도학습은 정답 없이 데이터의 패턴이나 군집을 찾는다.
  • KNN은 대표적인 지도학습 알고리즘 중 하나이다.

예제 파이썬 코드

from sklearn.neighbors import KNeighborsClassifier

# 공부 시간과 시험 점수 데이터
X = [[1], [2], [3], [4], [5]]
y = ["낮음", "낮음", "보통", "높음", "높음"]

# 지도학습 모델 생성
model = KNeighborsClassifier(n_neighbors=1)

# 학습
model.fit(X, y)

# 예측
result = model.predict([[4]])

print("예측 결과:", result[0])

예상 출력

예측 결과: 높음

상세 설명

이 예제는 기계학습 개념과 지도학습·비지도학습 비교의 핵심 개념을 코드로 표현한 것입니다. 입력 데이터, 모델 또는 판단 과정, 출력 결과를 연결하여 인공지능 문제 해결 흐름을 이해할 수 있습니다.

OX 퀴즈 5문항

OX 1. 기계학습은 데이터를 이용하여 규칙을 학습할 수 있다.
OX 2. 지도학습은 정답(label)이 없는 데이터만 사용한다.
OX 3. 비지도학습은 데이터의 패턴이나 군집을 찾는 데 활용될 수 있다.
OX 4. KNN 알고리즘은 대표적인 지도학습 알고리즘이다.

12정04-03 기계학습 활용과 사회문제 해결

성취기준
기계학습을 활용하여 해결할 수 있는 문제와 그렇지 않은 문제를 구분하고, 사회문제 해결에 기계학습을 적용한다.

기계학습을 활용하여 해결할 수 있는 문제와 그렇지 않은 문제를 명확히 구분하고, 실생활 및 사회문제에 적합한 기계학습 유형을 적용하여 사회문제를 해결하기 위해 기계학습을 적극적으로 활용하는 자세를 내면화할 수 있다.

핵심 개념

  • 기계학습은 대량의 데이터에서 패턴을 학습하여 예측이나 분류에 활용될 수 있다.
  • 미세먼지 예측, 교통량 분석, 의료 진단 보조 등은 기계학습 활용 사례이다.
  • 윤리적 판단, 인간의 감정 공감처럼 데이터만으로 완전히 해결하기 어려운 문제도 있다.
  • 사회문제 해결에는 데이터 품질, 편향, 윤리, 인간의 최종 판단이 함께 고려되어야 한다.

예제 파이썬 코드

from sklearn.linear_model import LinearRegression
import numpy as np

# 날짜별 미세먼지 데이터
days = np.array([1, 2, 3, 4, 5]).reshape(-1, 1)
dust = np.array([30, 35, 40, 45, 50])

# 선형 회귀 모델 생성
model = LinearRegression()

# 학습
model.fit(days, dust)

# 예측
prediction = model.predict([[6]])

print("6일차 예측 미세먼지:", int(prediction[0]))

예상 출력

6일차 예측 미세먼지: 55

OX 2. 기계학습은 모든 사회문제를 완벽하게 해결할 수 있다.
OX 3. 미세먼지 예측은 기계학습 활용 사례가 될 수 있다.
OX 4. 기계학습은 데이터가 많을수록 더 유용하게 활용될 수 있다.
OX 5. 인간의 감정 공감 문제는 기계학습만으로 완전히 해결 가능하다.
