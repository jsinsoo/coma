12정03-01 문제 분해와 모델링

성취기준
복잡한 문제를 해결 가능한 작은 문제로 분해하고 모델링한다.
문제 분해와 모델링 적용 방법을 설명하고, 문제를 해결 가능한 작은 단위의 문제로 효율적으로 분해하고, 컴퓨팅 시스템에서 처리 가능한 단순화나 구조화된 형태로 적합하게 모델링한다.

핵심 개념

  • 문제 분해: 큰 문제를 작은 기능으로 나눈다.
  • 추상화: 핵심 정보만 남기고 불필요한 세부사항을 줄인다.
  • 모델링: 현실 문제를 컴퓨터가 처리 가능한 자료와 절차로 표현한다.

예제 파이썬 코드

def calculate_average(scores):
    total = sum(scores)
    count = len(scores)
    return total / count

def find_highest(scores):
    return max(scores)

def need_improvement(average):
    if average < 80:
        return "개선 필요"
    else:
        return "양호"

meal_scores = [85, 70, 90, 75, 80]

average = calculate_average(meal_scores)
highest = find_highest(meal_scores)
status = need_improvement(average)

print("평균 만족도:", average)
print("최고 만족도:", highest)
print("분석 결과:", status)

12정03-02 정렬 알고리즘 특징과 효율 비교

성취기준
데이터를 정렬하는 다양한 알고리즘의 특징과 효율을 비교ㆍ분석한다.
다양한 정렬 알고리즘의 원리와 수행 과정을 설명하고, 정렬 알고리즘별 특징과 효율성을 비교한다.

핵심 개념

  • 버블 정렬: 인접한 두 값을 비교하고 교환한다.
  • 삽입 정렬: 정렬된 구간에 새 값을 삽입한다.
  • 병합/퀵 정렬: 분할 정복을 활용하며 평균적으로 효율적이다.

예제 파이썬 코드

def bubble_sort(data):
    arr = data[:]
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

def insertion_sort(data):
    arr = data[:]
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

scores = [64, 25, 12, 22, 11]
print("버블 정렬:", bubble_sort(scores))
print("삽입 정렬:", insertion_sort(scores))
print("원본 데이터:", scores)

12정03-03 탐색 알고리즘 특징과 효율 비교

성취기준
데이터를 탐색하는 다양한 알고리즘의 특징과 효율을 비교ㆍ분석한다.
순차 탐색, 이진 탐색, 해시 탐색의 원리와 효율성을 비교한다.

핵심 개념

  • 순차 탐색: 정렬되지 않은 데이터에도 사용 가능하다.
  • 이진 탐색: 정렬된 데이터에서 범위를 절반씩 줄인다.
  • 해시 탐색: set, dict를 이용해 평균적으로 빠른 탐색이 가능하다.

예제 파이썬 코드

def linear_search(data, target):
    for index in range(len(data)):
        if data[index] == target:
            return index
    return -1

def binary_search(data, target):
    left = 0
    right = len(data) - 1
    while left <= right:
        mid = (left + right) // 2
        if data[mid] == target:
            return mid
        elif data[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

numbers = [3, 8, 12, 15, 21, 30, 42]
target = 21
print("순차 탐색 위치:", linear_search(numbers, target))
print("이진 탐색 위치:", binary_search(numbers, target))
print("해시 탐색 결과:", target in set(numbers))

예제 파이썬 코드

class EnergyAnalyzer:
    def __init__(self, usage_data):
        self.usage_data = usage_data

    def average_usage(self):
        total = sum(self.usage_data.values())
        count = len(self.usage_data)
        return total / count

    def find_high_usage_rooms(self):
        average = self.average_usage()
        result = []
        for room, usage in self.usage_data.items():
            if usage > average:
                result.append(room)
        return result

usage = {"1반": 18, "2반": 25, "3반": 21, "4반": 30}
analyzer = EnergyAnalyzer(usage)
print("평균 사용량:", analyzer.average_usage())
print("절약 점검 대상:", analyzer.find_high_usage_rooms())

12정03-10 프로그램 성능 평가와 공유

성취기준
문제 해결을 위한 프로그램의 성능을 평가하고 공유한다.
정확성, 실행 시간, 메모리 사용량, 가독성, 공유와 피드백을 기준으로 프로그램 성능을 평가한다.

핵심 개념

  • 정확성: 올바른 결과를 출력하는지 확인한다.
  • 효율성: 실행 시간과 메모리 사용량을 고려한다.
  • 공유와 피드백: 측정 조건, 결과, 개선점을 함께 제시한다.

예제 파이썬 코드

import time

numbers = list(range(1, 100001))
target = 99999

start = time.time()
found1 = False
for n in numbers:
    if n == target:
        found1 = True
        break
linear_time = time.time() - start

start = time.time()
number_set = set(numbers)
found2 = target in number_set
set_time = time.time() - start

print("순차 탐색 결과:", found1)
print("집합 탐색 결과:", found2)
print("순차 탐색 시간:", linear_time)
print("집합 탐색 시간:", set_time)
